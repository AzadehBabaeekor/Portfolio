Voici mes compétences en programmation:

Le HTML (HyperText Markup Language, ou langage de balisage hypertexte) est le langage de base utilisé pour créer et structurer le contenu d'une page web. Le HTML fonctionne avec des balises (tags) placées entre chevrons (< >). La plupart du temps, une balise s'ouvre, contient du texte ou d'autres balises, puis se ferme avec un slash (/).

Le CSS (Cascading Style Sheets ou feuilles de style en cascade) est le langage informatique utilisé pour mettre en forme et styliser les pages web écrites en HTML. Une règle CSS est toujours composée de deux grands éléments: 1. Un sélecteur : il indique quel élément HTML on souhaite modifier. 2. Un bloc de déclaration (entre accolades { }) : il contient une ou plusieurs paires de propriété : valeur ; .

Python est un langage de programmation informatique de haut niveau, interprété et polyvalent. Créé par Guido van Rossum et sorti en 1991, il est conçu pour être très facile à lire et à écrire, avec une syntaxe proche de la langue anglaise. Ses caractéristiques principales sont : 1. langage interprété et 2. Syntaxe simple .

RISC-V (prononcé « risk-five ») est une architecture de jeu d'instructions (ISA) libre, ouverte et gratuite, créée en 2010 par des chercheurs de l'Université de Californie à Berkeley. Elle repose sur un ensemble d'instructions simple et réduit, ce qui permet une exécution rapide des tâches et une efficacité énergétique (souvent comparée aux architectures ARM ou x86 )

Le langage C est un langage de programmation impératif et généraliste créé en 1972 par Dennis Ritchie aux laboratoires Bell pour développer le système d'exploitation Unix. Il est un langage de bas niveau avec de faciliotés de haut niveau. Il offre un contrôle direct sur la mémoire, les registres et le matériel. Il fait partie de langages compilés; Le code source est transformé en code machine par un compilateur avant d'être exécuté, ce qui le rend extrêmement rapide.

Un shell est un programme qui fait office d'intermédiaire entre l'utilisateur (ou un script) et le système d'exploitation Unix / Linux. Il lit les commandes tapées dans un terminal et demande au noyau (kernel) de les exécuter. Bash (Bourne-Again SHell) est le shell par défaut le plus répandu sur les systèmes Linux et macOS. C'est une évolution améliorée du shell historique sh (Bourne Shell) créé en 1978. Les Shells Unix sont des langages de script qui permettent d'écrire des fichiers d'automatisation.
